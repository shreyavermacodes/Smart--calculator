# Smart--calculator
A feature-rich Smart Calculator developed in Python that performs basic and advanced mathematical operations through an easy-to-use menu-driven interface.
Smart Calculator – Python


Features

-  Addition
- Subtraction
-  Multiplication
-  Division
-  Modulus
-  Power
-  Square Root
-  Trigonometric functions
  - sin
  - cos
  - tan
-  Logarithmic calculations
-  Factorial
-  Percentage calculation
-  Advanced mathematical operations
-  Calculation history
-  Multiple calculations without restarting
-  Exit option
-  Error handling for invalid inputs and division by zero

 Technologies Used

- Python 3
- "math" module

 Python Concepts Used

- Input and output
- Conditional statements
- Loops
- Functions
- Exception handling
- Lists
- Mathematical functions
- Module
